# Лабораторная работа № 3 — метод опорных векторов

Системы искусственного интеллекта · Михайлов Петр Сергеевич, P3311  
Преподаватель — Королёва Юлия Александровна.

В работе реализована линейная SVM с мягким зазором, L2-регуляризацией и обучением по мини-пакетам. Исследуются регуляризация, размер пакета и масштабирование. Модель сравнивается с собственной логистической регрессией из ЛР1 на одном разбиении. Разбиение, стандартизация, субградиенты и метрики реализованы самостоятельно; тензорные вычисления выполняются в PyTorch.

## Запуск

Из папки «Лабораторная 3»:

```bash
py -m venv .venv
./.venv/Scripts/python.exe -m pip install -r requirements.txt
./.venv/Scripts/python.exe -m notebook lab3.ipynb
```

В ноутбуке выполнить **Restart Kernel and Run All Cells**. Для Linux и macOS можно использовать `python3 -m venv .venv` и `.venv/bin/python`. Расчёт работает на CPU; выполнение экспериментов занимает некоторое время. Графики и численные результаты сохраняются в `docs/`.

## Данные и оценка

Volker Lohweg, [Banknote Authentication](https://doi.org/10.24432/C55P57), UCI Machine Learning Repository, 2012, CC BY 4.0. CSV и TXT содержат одинаковые записи; для загрузки используется CSV с названиями столбцов. Из 1372 строк удаляются 24 точных повтора до разбиения. Целевая переменная — `class`; класс 1 рассматривается как положительный.

Для случайных операций используется `seed=6752`. Параметры масштабирования вычисляются по train, гиперпараметры и число эпох выбираются на validation. Итоговые метрики вычисляются на test; площади ROC и PR определяются методом трапеций по непрерывным оценкам моделей.
